# إشراق | معك لمستقبل طموح

منصة برنامج **إشراق** الإرشادي التابع لجمعية البطالية الخيرية: صفحة تعريفية تفاعلية، ولوحات خاصة للإدارة والمرشد والمستفيد. البيانات محفوظة في Firebase Realtime Database.

## التشغيل والنشر

الموقع ملفات ثابتة (HTML / CSS / JS) لا تحتاج إلى أي بناء.

- **GitHub Pages:** من إعدادات المستودع ← Pages ← اختر الفرع `main` والمجلد `/ (root)`.
- **محلياً:** `python3 -m http.server` ثم افتح `http://localhost:8000`.

## الإعدادات — `js/config.js`

| المفتاح | الوصف |
|---|---|
| `firebase.databaseURL` | رابط قاعدة البيانات (مُعدّ مسبقاً). اجعل `firebase: null` للعمل محلياً على المتصفح فقط. |
| `dbRoot` | المسار الجذري للبيانات داخل القاعدة (`ishraq`). |
| `adminCode` | الرمز السري لدخول الإدارة (`2026`). |

عند أول تشغيل تُعبّأ القاعدة تلقائياً بالمحتوى الافتراضي المستخرج من الدليل التشغيلي، إضافة إلى الدفعتين الأولى (2025) والثانية (2026).

### قواعد Firebase

انسخ محتوى `database.rules.json` إلى Firebase Console ← Realtime Database ← Rules. القواعد الحالية مفتوحة للقراءة والكتابة على مسار `ishraq`، لأن المنصة لا تستخدم تسجيل دخول Firebase (الدخول برموز داخل الصفحة).

> ⚠️ **ملاحظة أمنية:** الرمز السري للإدارة ورموز العضوية يُتحقق منها داخل المتصفح. من يعرف رابط قاعدة البيانات يستطيع تقنياً قراءة البيانات وتعديلها. لحماية أعلى يُنصح لاحقاً بتفعيل Firebase Authentication وتقييد القواعد.

## النسخ الاحتياطي

في أعلى لوحة الإدارة شريط «النسخ الاحتياطي»:

- **نسخة احتياطية:** تنزيل ملف JSON بكل بيانات المنصة: المحتوى، والأعضاء، والجلسات، والتقييمات، والفعاليات، والمهتمون، والرسائل. يُنصح بأخذ نسخة أسبوعياً، ويتحول الشريط إلى اللون الأصفر إذا مضى أسبوع على آخر نسخة.
- **استرجاع نسخة:** اختيار ملف نسخة سابقة لاستبدال البيانات الحالية بها بعد التأكيد. قبل الاسترجاع تُنزَّل نسخة من البيانات الحالية تلقائياً للاحتياط. يقبل أيضاً ملفات «Export JSON» من Firebase Console.

## رموز الدخول

- **الإدارة:** `2026`
- **المرشد:** `M` + رقم الدفعة + تسلسل يبدأ من `11`. مثال: `M211` هو أول مرشد في الدفعة الثانية.
- **المستفيد:** `B` + رقم الدفعة + تسلسل يبدأ من `11`. مثال: `B111` هو أول مستفيد في الدفعة الأولى.

الرموز تتولد آلياً عند إضافة العضو ولا يتكرر استخدامها، ولا يُفرّق فيها بين الحرف الكبير والصغير.

## الخطوط

تُحمَّل من Google Fonts، ومعرّفة كمتغيرات في `css/style.css`:

| المتغير | الخط | الاستخدام |
|---|---|---|
| `--f-display` | **Cairo** (600–900) | العناوين h1–h4، واسم البرنامج، والأسماء، والأرقام البارزة (الإحصاءات ومؤشرات لوحة الإدارة وعدادات الجلسات) |
| `--f-ui` | **IBM Plex Sans Arabic** | الأزرار والشارات والوسوم والتسميات والتلميحات والجداول والقوائم |
| `--f-body` | **Noto Sans Arabic** | النص الأساسي وخانات الإدخال والنماذج |

الأرقام إنجليزية دائماً، وتأخذ خط المكان الذي تظهر فيه. تنسيق `.num` يجعل عرض الأرقام متساوياً ويثبّت اتجاهها من اليسار لليمين داخل النص العربي. صورة البطاقة التعريفية المحفوظة تستخدم الخطوط الثلاثة نفسها.

